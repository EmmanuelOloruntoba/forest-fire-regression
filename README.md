# Forest Fires Regression Project

Predicting the burned area of forest fires in northeast Portugal using the UCI Machine
Learning Repository's **Forest Fires** dataset (Cortez & Morais, 2007).

## Project Structure

```
forest-fires-regression/
├── data/
│   ├── forestfires.csv       # Raw dataset (517 rows, 12 features + target)
│   └── forestfires.names     # UCI dataset documentation
├── notebook/
│   └── forest_fires_regression.ipynb   # Full analysis, modeling, and evaluation
├── outputs/
│   └── figures/               # All plots generated by the notebook, saved as PNG
├── requirements.txt

```

## Setup

```bash
pip install -r requirements.txt
jupyter notebook notebook/forest_fires_regression.ipynb
```

Run the notebook top-to-bottom; it is fully reproducible (`random_state=42` fixed
throughout) and requires no external data beyond what's in `data/`.

## Problem

Predict `area` (hectares burned) from 12 pre-fire predictors: spatial grid coordinates
(`X`, `Y`), calendar information (`month`, `day`), four Canadian Forest Fire Weather Index
components (`FFMC`, `DMC`, `DC`, `ISI`), and four weather readings (`temp`, `RH`, `wind`,
`rain`).

## Approach (see the notebook for full reasoning behind every step)

1. **Data quality**: investigated 4 apparent "duplicate" rows and found — using evidence
   about how the FWI system generates data — that 3 were legitimate distinct fires sharing
   a same-day/same-location weather reading, and only 1 was a genuine duplicate record.
2. **Target investigation**: `area` is extremely skewed (47.87% exact zeros, skewness
   ≈12.84). `log1p(area)` was investigated and used as a modeling target, tested — not
   assumed — against the raw scale.
3. **EDA**: every predictor's individual linear correlation with `area` is weak (|r| <
   0.15) — a genuinely hard regression problem, not a modeling shortfall.
4. **Feature engineering**: cyclical `month_sin`/`month_cos` encoding, one-hot `day`, and a
   domain-justified `temp_wind` interaction (later confirmed important by both models'
   feature importance, despite weak raw correlation).
5. **Modeling**: Baseline (mean) → Linear Regression → Random Forest, each on both the raw
   and `log1p` target, evaluated via 5-fold stratified cross-validation.
6. **Key finding**: on the raw scale, neither model beat the naive baseline. `log1p`
   training roughly halved MAE and was the only approach to beat the baseline — but
   diagnostics showed both models still **severely underpredict large fires** (predicting
   ~2-3 ha for fires that actually burned >100 ha on average).

## Final Model

**Linear Regression, trained on `log1p(area)`**, selected over a statistically-tied
Random Forest alternative for its stability (near-zero train/validation gap) and full
interpretability. On a held-out test set (touched exactly once):

| Metric | Baseline | Final Model (Linear, log1p) |
|---|---|---|
| MAE | 14.75 ha | **7.79 ha** |
| RMSE | 18.51 ha | **18.20 ha** |
| R² | -0.14 | -0.10 |

## Known Limitation

The final model is suitable for estimating **typical** expected burned area, but is
**not** adequate as an early-warning tool for severe fires — the underprediction of large
fires is systematic and replicates on the held-out test set. See the notebook's
Conclusions & Limitations section for the full discussion and recommended next steps
(two-stage/hurdle modeling, gradient-boosted trees, location-grouped cross-validation).
